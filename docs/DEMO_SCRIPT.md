# Judge walkthrough and video plan

## 30 seconds

0–5: Start Journey → Mars → Lucus Planum → Find Earth terrain.
5–15: Point to the analog percentages. Select a discovered candidate. Say: “This is a new terrain window near a known region; local geology is not reviewed.”
15–25: Open More: evidence and limits. Contrast analog match with the fixed-lander landing behaviour result. Explain that neither is validated accuracy.
25–30: Credits → Findings. Show the generated per-target results and limitations.

## Three minutes

0:00–0:25: Start Journey → Moon → Marius Hills → Find Earth terrain. The ten preserve research-tier priority. Select an Earth site, read its match percentage and More evidence. Earth cannot reproduce lunar gravity, vacuum or radiation.
0:25–0:50: Change test site → Explore all 102 test grounds. Every site has its target-specific engineering similarity, not a percentage probability of suitability. Select a cyan/discovered candidate; its inferred geology is visibly unreviewed.
0:50–1:15: Return to title via the wordmark → Atlas. Use Compare with to switch to Mars / Lucus Planum. White markers are curated; cyan are scanned; gold is selected. Explain that the scan searches windows near justified known regions, not every desert on Earth.
1:15–1:40: Select a discovered window → Select Equipment → Launch Journey. Use Skip on cinematics if needed. On the bridge open Mission control and point out match, difference and the separate baseline landing comparison. Custom equipment changes physics and therefore requires its own simulation.
1:40–2:40: Launch the experiment. Let the actual autonomous physics reach an outcome; do not claim a scripted success. Use 2D view if the device struggles. After touchdown the astronaut walks to the mission-control monitor and the report opens on its screen. Use the left/right arrows (or arrow keys) to page through eight sections: touchdown and what Earth cannot reproduce, landing assessment, limits, statistics, rehearsal flights, analog fidelity with the catalog landing baseline, analog match evidence and site conditions. Skip to report is always available; reduced motion opens it directly. If the flight exceeds this segment, show the findings while it finishes or use a prerecorded complete flight.
2:40–3:00: Credits → Findings. Read one difference aloud. State limits: coarse planetary grids, terrain-only benchmark AUC 0.50, unreviewed local geology, no independent scientific validation. Explain the next step: field review and finer planetary data.

## Fallback and video

If rendering is unavailable altogether, `/findings.html` contains the generated results and method; never replace it with a fabricated flight.

Record 1080p landscape screen capture and narration: 15 seconds mission selection, 25 seconds evidence/discoveries, 20 seconds settings, 50 seconds a real flight (time compression labelled), 35 seconds debrief/findings, 15 seconds limitations. Add source URLs and the live link to the video description. A recorded fallback must show its actual build and must not imply live telemetry.
