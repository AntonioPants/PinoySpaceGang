Planetary Analog Landing Simulator

Every piece exists. Now they have to be joined.

Pick a Moon or Mars site, see a matching Earth analog, configure a lander, fly the descent over real terrain, and read an engineering report. The data, the physics, the interface and the cutscenes are all in the repository. What is left is mostly joining them and shipping.

Known gaps

A red square blocks a good demo. A black square is a known limit that can ship as it is.

  • Cutscenes are not wired in

    The descent screen does not play the opening or the ending.

  • Nothing is deployed

    There is no public URL, no demo video and no submission text.

  • Untested by a human

    Manual flying, the cutscenes in motion, and sound. So far they have only been checked as still frames.

  • No rock data

    No site has a measured rock abundance, so real terrain has no boulders.

  • Coarse planetary terrain

    Moon and Mars grids are 150 to 500 m per sample, so every planetary site scores 100% landable in the stress test.

  • Stale documents

    CLAUDE.md and the mission plan page describe an earlier state.

  • Housekeeping

    Five merged branches on GitHub can be deleted, and the zip and its unzipped folder are still in the repository folder, uncommitted.

Flight plan

In order. Each step builds on the one before it.

  1. 1
    Merge Eyad's branch into main

    Run its tests first. Every later step builds on it.

  2. 2
    Wire the cutscenes into the flow

    The opening plays before the descent and the ending before the report. This is the biggest visible gain for a demo.

  3. 3
    Decide the look

    Restyle all five screens in the 1976 style, or drop the trial. It is Eyad's call.

  4. 4
    Play-test by hand

    One full run per target, manual mode included, with the sound on.

  5. 5
    Ship

    Deploy to a public URL, add the data attribution page, record the demo, and write the submission.

  6. 6
    Only if time remains

    Real rock abundance and finer planetary terrain.
